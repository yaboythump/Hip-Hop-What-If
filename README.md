# Hip Hop What If

Automated episode production system for the Hip Hop What If YouTube channel.

## Goal

Keep the creative episode production style exactly the same while removing paid upload middleware.

## Workflow

1. User chooses the next episode topic.
2. The system builds the episode package.
3. Higgsfield produces the finished episode.
4. The finished MP4 and Shorts are uploaded directly to YouTube.
5. Episode and Shorts naming stay matched.

## Protected rule

Do not change the episode look, format, naming style, or production feel unless explicitly requested.
