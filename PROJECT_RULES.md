# Hip Hop What If Project Rules

## Main rule

Do not change the episode look, format, voice, naming style, pacing, or production feel unless Thump explicitly asks for it.

## Current production goal

Keep Higgsfield as the episode creator.

Remove paid upload middleware.

Upload finished episodes and Shorts directly to YouTube.

## Episode control

Thump chooses the next episode topic manually.

The workflow must not randomly pick topics unless that feature is requested later.

## Naming rule

The main episode and Shorts must share the same base episode topic.

Example:

Main episode:
What If Tupac Signed With No Limit?

Shorts:
What If Tupac Signed With No Limit? | Short #1
What If Tupac Signed With No Limit? | Short #2
What If Tupac Signed With No Limit? | Short #3

## Upload rule

All test uploads must start as private.

Do not publish publicly until direct YouTube upload is confirmed working.
